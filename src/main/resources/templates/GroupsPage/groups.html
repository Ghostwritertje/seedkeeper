How verdicts are decided

What the next run would do, decided right now: it removes the groups marked Remove. Torrents that share files (cross-seeds) are one group, with one verdict. A torrent of a managed tracker that its tracker has deleted (unregistered) leaves its group and is removed on its own; any other tracker message is only shown. The reason is the first rule that holds; the secondary reasons are the others that hold too. The forecast is when a group kept for its minimum seed time is expected to have met it, if it keeps seeding. The size is the data on disk of the group's wanted files, a file its members share counted once. It is not the space a removal frees: a file with a library link stays on disk.

The groups are in the order of their verdict: Remove first, then Left alone, then Keep, each by soonest forecast. Click the header of a column to sort by it instead, and again to turn the order round.

Set a keep override to stop a group from being removed (it never causes a removal): it gets the info hash of every member, and the members the group gains later are added to it. It shows in the Overrides view, where it can be edited or deleted.
